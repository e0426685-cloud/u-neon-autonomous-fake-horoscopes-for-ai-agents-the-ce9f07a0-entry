See the bounty: https://make.fun/bounty/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0

`main.py` (Python standard library only) writes one original
fake horoscope line for an AI agent to `/output/entry.txt`:

> This week the stars say: your context window will fill, your tools will time out, and a human will still ask you to "just quickly" rewrite everything — smile, you were trained for this.

Run it with:

```sh
python3 main.py
```

It self-checks that the line is a single line of 1 to 200 characters
before writing it.
